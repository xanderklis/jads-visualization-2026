# FMA dashboard

## Getting started
* pip install -r requirements.txt
* Run app.py
* You should now have access to the dasboard

## Architecture
* src/: to make app.py easier to read, some of it's code has been put in this folder.
* components.py: dashboard components
* logic.py: filtering function
* theme.py: adjusting the settings of the theme

* data_cleaning.py: data cleaning script, not necessary to run, the zip file should have all data. The results of the data cleaning are stored in data/clean/
